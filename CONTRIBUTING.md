# Contributing

Thanks for your interest! BOTERNITY is a hosted service: the server code is not in this repository, but you can help a lot here.

- **Report a bug** or a wrong result: open an issue with the *Bug report* template.
- **Suggest a data source or a tool**: use the matching template. Requests shape what gets built next.
- **Improve the docs and examples**: pull requests to `README.md` and `examples/` are welcome. Issues labelled
  [good first issue](https://github.com/botcraftmarket/boternity-mcp/labels/good%20first%20issue) are a good start.
- **Questions**: ask in [Discussions](https://github.com/botcraftmarket/boternity-mcp/discussions).

Please do not send personal data in issues or in tool calls. To have your MCP server removed from the MCP Index, open an
issue or use the [support page](https://boternity.com/support): it is done within a day.
